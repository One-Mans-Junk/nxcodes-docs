# Your First Game

Let's create a simple game in 30 minutes.

## Step 1: Access Admin Panel

Navigate to your domain with `/admin` and log in with your admin credentials.

## Step 2: Configure Game Settings

1. Go to **Settings** then **General**
2. Set your game name
3. Configure timezone
4. Save changes

## Step 3: Enable Modules

1. Go to **Modules**
2. Enable the modules you want:
   - User Stats
   - Gym
   - Crimes
   - Battle

## Congratulations!

Your game is now ready for players!
