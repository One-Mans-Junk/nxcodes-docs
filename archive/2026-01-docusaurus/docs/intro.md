# Welcome to NXCodes

**NXCodes** is a browser-based game engine built with Laravel 12 that lets anyone create multiplayer text-based RPG games - no coding experience required.

## What Can You Build?

- 🎮 Mafia/Crime games
- ⚔️ Fantasy RPGs
- 🏰 Kingdom builders
- 🚀 Space exploration games
- 💰 Trading/Economy games

## Why NXCodes?

| Feature | Benefit |
|---------|---------|
| **No Coding Required** | Build games using the admin panel |
| **Modular Design** | Enable only the features you need |
| **Built on Laravel 12** | Modern, secure, scalable |
| **Beginner Friendly** | Detailed docs for every step |
